# Mergington High School Activities

A super simple website application that allows students to view and sign up for extracurricular activities.

## Features

- View all available extracurricular activities
- Filter activities by difficulty, category, day, and time
- Sign up for activities

Activities may have an optional `difficulty` field set to `Beginner`,
`Intermediate`, or `Advanced`. Leave it out for activities open to all levels.
The difficulty filter's **All** option shows only activities without a specified
level; **Show all** displays activities regardless of difficulty.
